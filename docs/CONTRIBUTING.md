# Contributing

Small commits, Conventional Commits (`feat:`, `fix:`, `security:`, `test:`, `docs:`, `refactor:`, `chore:`, `ci:`).
Never force-push or rewrite history without the owner's permission. One milestone at a time; the owner approves with "go".
Dependencies are pinned exactly; add new ones only with a reason, and prefer versions at least 14 days old.
