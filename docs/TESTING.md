# Testing

- `pnpm test` runs Vitest (unit + boundary tests). `pnpm check` runs everything required before a commit.
- Pre-commit hook (Husky) runs format check, lint and typecheck; commit messages follow Conventional Commits.
- Real results are recorded per milestone in the milestone report, not here.
- Not yet present: integration tests, Playwright E2E, load, accessibility, Lighthouse.
